# 御端 YuDuan · 企业终端统一管理平台

> 主端 + 副端架构，面向企业内网的终端集中管控与远程协助平台。
> 当前阶段：**局域网（LAN）内管控**，公网远程控制为远期目标，本期不涉及。

## 一句话定位
公司 IT 运维通过**主端（跨平台管理客户端）**在局域网内集中管理所有员工电脑（**副端 Agent**），
实现设备资产清点、向日葵式远程协助、软件/文件统一下发，降低千台级终端的维护成本。

## 核心能力（规划）
- **资产管理**：硬件 / 软件 / 网络 / 安全状态自动采集与台账。
- **远程控制**：局域网内屏幕查看、控制、会话内文件传输、录像、远端强制提示、权限分级审批。
- **软件分发**：主端软件仓库 → 副端静默安装，状态可追踪。
- **策略与合规**：合规基线、策略中心、告警、审计、报表。
- **系统管理**：组织架构 / RBAC / 批量部署。

## 平台支持
主端、副端均支持 **Windows / macOS / Linux** 三平台同构部署（本期仅限局域网）。

## 技术栈（参考，详见开发文档）
- 服务端中枢：Go + PostgreSQL + MinIO/NAS
- 主端：Tauri（Rust + React）跨平台桌面客户端
- 副端：Rust 系统服务（Windows Service / macOS launchd / Linux systemd）
- 通信：WebSocket + TLS，指令 HMAC-SHA256 签名 + 序列号防重放
- 远控：自研轻量 RDP-lite（H.264/H.265 编码，LAN 直连或中枢中继）
