# 管理控制台（控制台网页）

M2/M3 阶段的主端管理界面以单页 Web 应用呈现，后续由 Tauri/React 桌面壳包装（铁律：主端为跨平台桌面客户端）。

## 功能
- **资产台账**：实时列出纳管设备（主机 / OS / Arch / CPU / 内存 / 磁盘 / IP / MAC / Agent 版本 / 在线状态），每 3s 轮询刷新。
- **汇总报表**：纳管总数 / 在线 / 离线 卡片。
- **指令下发**：选择设备 → 选 `shell` 或 `collect` → 执行并展示返回结果（含 exit_code 与输出）。

## 实现
- 文件：`console/index.html`（零构建，原生 HTML/JS）
- 由中枢 `GET /` 直接托管，同源访问 `REST /api/v1/*`。
